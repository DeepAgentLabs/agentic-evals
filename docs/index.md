# Agentic Evals

Did the recorded behavior meet our quality requirements?

## What it does

Per-case scores, summary metrics, and a separate release-gate decision.

## What you need

Test cases, actual outputs, normalized traces, and optional judge callbacks.

## Start here

Evaluate two recorded answers, then add tool evidence.

[Follow the quickstart](developer-guide.md#quickstart).

## Scope

A report is not a release approval. Tool checks require complete tool evidence; optional model judges need your provider integration.

[Read the detailed developer guide](developer-guide.md).
